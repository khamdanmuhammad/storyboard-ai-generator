Mengapa API Key Diperlukan?

Saat dipublikasikan di Vercel, website berjalan mandiri. Agar sistem dapat memanggil AI Google Gemini, Anda memerlukan API Key gratis resmi dari Google.

  1. Buka situs Google AI Studio (aistudio.google.com)
  2. Login dengan akun Gmail Anda.
  3. Klik tombol "Create API Key".
  4. Salin kode kunci (diawali AIzaSy...) dan tempel di bawah ini.
